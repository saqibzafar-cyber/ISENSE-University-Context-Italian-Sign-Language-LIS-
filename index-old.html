01 / About the project

Researching sign language through visual data

The ISENSE Dataset is a sign-language research resource associated with the University of Tuscia. Its website provides a central place for researchers to learn about the dataset, review the conditions of use, and request authorized access.

ISENSE is intended to support computational research, including studies involving computer vision, machine learning, and sign-language recognition. Specific dataset characteristics and scientific results should be documented in the accompanying dataset paper and technical documentation.

02 / Research applications

Built for computational research

The resource is intended to facilitate responsible investigations of visual sign language data. The examples below describe possible research applications, not benchmark results.

Sign language recognition

Investigate models and methods for recognizing or analyzing signed communication from visual data.

Computer vision and AI

Develop and evaluate computational approaches, feature representations, and machine learning systems.

Responsible evaluation

Study research performance while respecting participant privacy, provenance, and permitted data use.

03 / Dataset access

04 / Usage & privacy

Research access with clear safeguards

The current ISENSE license and disclaimer permits approved, non-commercial academic and scientific research. Other uses require prior written authorization from the authorized dataset provider.
